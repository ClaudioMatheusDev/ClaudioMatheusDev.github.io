Sobre

Backend com foco em código que dura

Sou desenvolvedor backend com foco no ecossistema .NET. Gosto de problemas de domínio reais: pagamentos, notas fiscais com baixa de estoque, auditoria de dados e monitoramento de jobs de ETL.

Separo os projetos em camadas (API, Application, Domain, Infrastructure), escrevo testes com xUnit e trato desde o início de autenticação, idempotência, resiliência entre serviços e logs estruturados. Também trabalho no front-end com Angular e React quando o projeto pede.

  • Arquitetura em camadasDomínio isolado, dependências apontando para dentro
  • MicrosserviçosComunicação HTTP com retry/circuit breaker e mensageria com RabbitMQ
  • DadosSQL Server, EF Core, Dapper, procedures, views e triggers
  • QualidadeTestes com xUnit, Moq e NSubstitute; logs com Serilog
