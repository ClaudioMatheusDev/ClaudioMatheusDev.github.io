Sobre

Backend com foco em código que dura

Sou desenvolvedor backend .NET com quase 2 anos de experiência profissional em C#, SQL Server e integração entre sistemas. No trabalho, desenvolvo e mantenho integrações de dados entre Oracle, SQL Server e MySQL, otimizo consultas T-SQL e Stored Procedures e diagnostico falhas em produção.

Nos projetos pessoais, construo APIs REST com ASP.NET Core e Entity Framework Core em camadas (API, Application, Domain, Infrastructure), com testes automatizados, CI e atenção desde o início a autenticação, idempotência e logs estruturados. Sou criador do AuditLogCM, biblioteca open source publicada no NuGet, e estou no 8º semestre de Ciência da Computação.
